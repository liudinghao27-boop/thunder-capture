🧠 雷霆捕获系统｜AI矩阵工程级重构方案（v2.0）
1. 项目重构目标
当前系统问题：
AI能力仅用于“分类与话术生成”
缺少统一 Agent 架构
设备控制与业务逻辑耦合严重
无视觉理解与状态建模
缺少任务级“闭环决策系统”
🎯 重构目标
升级为：
AI Agent驱动的多设备智能执行矩阵系统
核心能力：
多设备协同（Device Matrix）
AI决策闭环（LLM Planner）
屏幕视觉理解（Vision Perception）
状态驱动执行（Stateful Execution）
可扩展任务系统（Task Graph）

3. 模块重构说明
3.1 engine/ → 拆分为 AI Agent 核心层
❌ 当前问题
sender.py = 直接执行发送逻辑
queue.py = 简单任务队列
collectors = 强耦合采集逻辑
✅ 重构后结构
engine/
├── agent/
│   ├── planner.py        # AI决策器（核心）
│   ├── perception.py     # 屏幕/数据理解
│   ├── executor.py       # 动作执行器
│   ├── memory.py         # 任务记忆系统
│   └── state.py         # 状态建模
│
├── task/
│   ├── scheduler.py     # 任务调度器（升级queue）
│   ├── graph.py         # 任务流定义
│   └── router.py        # 任务分发
│
├── device/
│   ├── manager.py       # 设备统一管理•

4. AI Agent 核心设计（关键）
4.1 Planner（AI大脑）
职责：
理解任务
拆解步骤
输出结构化动作
输入：
{
"task" :"发送私信" ,
"context" :{}
}
输出：
{
"steps" :[
{"action" :"open_app" },
{"action" :"find_user" },
{"action" :"send_message" }
]
}
4.2 Perception（感知层）
输入：
screenshot
OCR结果
UI结构
输出：
{
"screen" :"wechat_chat" ,
"elements" :["输入框" ,"发送按钮" ]
}•
