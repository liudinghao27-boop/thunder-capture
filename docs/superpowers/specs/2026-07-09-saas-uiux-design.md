# 雷霆捕获系统 SaaS UI/UX 设计规范

> **文档版本**：v1.0  
> **创建日期**：2026-07-09  
> **关联 PRD**：`docs/superpowers/specs/2026-07-09-saas-prd.md`  
> **技术栈**：Vanilla JS + Tailwind CSS（保持现有栈，不重写框架）

---

## 1. 设计原则

1. **一致性**：所有页面使用同一套设计 tokens，禁止引入第二套组件库。
2. **信息密度优先**：管理后台以表格、卡片、状态徽章为主，减少装饰元素。
3. **移动端可用**：阶段 5 核心目标；优先保证"看数"和"简单操作"可用，不要求完整编辑。
4. **glass-panel 风格延续**：保留现有半透明/毛玻璃面板，统一升级为可复用 token。
5. **反 AI 塑料感**：避免过度圆角、过度渐变、无意义动效；保持工具感与专业感。

## 2. 设计 Tokens

### 2.1 颜色系统

```css
:root {
  /* 主色 */
  --color-primary-50:  #eef2ff;
  --color-primary-100: #e0e7ff;
  --color-primary-500: #6366f1;
  --color-primary-600: #4f46e5;
  --color-primary-700: #4338ca;

  /* 状态色 */
  --color-success: #10b981;
  --color-warning: #f59e0b;
  --color-danger:  #ef4444;
  --color-info:    #3b82f6;
  --color-neutral: #6b7280;

  /* 背景 */
  --bg-page:       #0f172a;   /* 深蓝灰页面背景 */
  --bg-panel:      rgba(30, 41, 59, 0.7);   /* glass 面板 */
  --bg-panel-solid:#1e293b;
  --bg-elevated:   rgba(51, 65, 85, 0.6);

  /* 文字 */
  --text-primary:   #f8fafc;
  --text-secondary: #94a3b8;
  --text-muted:     #64748b;
  --text-inverse:   #0f172a;

  /* 边框 */
  --border-default: rgba(148, 163, 184, 0.15);
  --border-focus:   var(--color-primary-500);
}
```

### 2.2 字体

| 用途 | 字体 | 备注 |
|------|------|------|
| 中文界面 | 系统默认（PingFang SC, Microsoft YaHei, Noto Sans SC） | 不引入网络字体，减少加载 |
| 数字/数据 | `ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas` | 等宽显示库存、限额 |
| 英文 | `Inter, system-ui, sans-serif` | 与 Tailwind 默认一致 |

### 2.3 间距系统

基于 Tailwind 4px 网格：

| Token | 值 | 用途 |
|-------|-----|------|
| space-1 | 4px  | 图标与文字间距 |
| space-2 | 8px  | 行内元素间距 |
| space-3 | 12px | 卡片内边距（紧凑） |
| space-4 | 16px | 卡片内边距（标准） |
| space-5 | 20px | 区块间距 |
| space-6 | 24px | 页面标题与内容间距 |
| space-8 | 32px | 大模块间距 |

### 2.4 圆角

| Token | 值 | 用途 |
|-------|-----|------|
| radius-sm | 6px  | 按钮、输入框、徽章 |
| radius-md | 8px  | 卡片、小面板 |
| radius-lg | 12px | 大卡片、弹窗 |
| radius-xl | 16px | 模态框、 onboarding 浮层 |

### 2.5 阴影

```css
--shadow-panel: 0 4px 24px rgba(0, 0, 0, 0.25);
--shadow-elevated: 0 8px 32px rgba(0, 0, 0, 0.35);
--shadow-glow-primary: 0 0 16px rgba(99, 102, 241, 0.3);
```

## 3. 响应式断点

沿用 Tailwind 默认断点：

| 断点 | 宽度 | 说明 |
|------|------|------|
| `sm` | 640px  | 小屏手机横向 |
| `md` | 768px  | 平板竖向 / 大屏手机 |
| `lg` | 1024px | 平板横向 / 小笔记本 |
| `xl` | 1280px | 桌面 |
| `2xl`| 1536px | 大屏桌面 |

### 3.1 移动端优先策略

- 所有新页面默认按 mobile-first 写 CSS。
- 关键页面在 375px 下必须可用（P0）。
- 复杂表单编辑在 375px 下可折叠为"查看摘要 + 进入桌面端编辑"。

## 4. 移动端适配方案

### 4.1 布局变化

| 元素 | 桌面（≥lg） | 移动端（<lg） |
|------|-------------|----------------|
| 导航 | 左侧固定侧边栏（240px） | 底部 Tab 栏（4 项：控制、线索、任务、我的） |
| 页面标题 | 左侧大标题 + 右侧操作按钮 | 顶部居中标题，操作按钮收入右下角 FAB |
| 卡片网格 | 多列 grid（2–4 列） | 单列堆叠 |
| 表格 | 完整表格 | 卡片列表，关键字段外露，详情展开 |
| 表单 | 多列并排 | 单列，高级选项折叠 |
| 统计图表 | 并排多个图表 | 轮播或纵向堆叠 |

### 4.2 优先适配的页面（阶段 5）

1. **控制中心（Dashboard）**：今日获客、任务状态、设备状态概览。
2. **线索池（Leads）**：列表卡片化、筛选器折叠为底部抽屉。
3. **设备状态（Devices）**：设备卡片、连接状态、限额进度条。

### 4.3 不强制移动端完整支持的页面

- 项目配置表单：移动端可查看摘要，复杂编辑引导至桌面端。
- A/B 实验创建：移动端只读列表。
- 管理后台（阶段 6）：桌面优先。

**桌面**：标准表格，列包括：状态徽章、用户、来源关键词、意向分类、采集时间、操作。

```
└─────────────────────────────┘
```

### 5.3 设备状态（Devices）

**桌面**：设备卡片网格，每张卡片显示设备名、在线状态、今日发送量/限额、最后心跳。

**移动端**：垂直卡片列表，发送量用进度条展示。

### 5.4 注册登录页（阶段 6）

**设计要点**：

- 居中卡片，最大宽度 420px。
- 分步骤：注册 → 邮箱验证 → 创建首个项目。
- 明确展示用户协议与隐私政策链接。
- 错误提示 Inline，不弹窗。

### 5.5 订阅/套餐页（阶段 6）

**设计要点**：

- 三档卡片并排（桌面），移动端垂直堆叠。
- 当前套餐高亮显示。
- 用量进度条：项目数、设备数、月发送量。

### 6.3 命名规范

| 类型 | 命名规则 | 示例 |
|------|----------|------|
| 组件文件 | kebab-case，语义化 | `glass-panel.js` |
| CSS 类 | Tailwind 工具类优先；自定义类以 `tc-` 前缀 | `tc-glass`, `tc-status-badge` |
| 颜色 token | CSS 自定义属性 | `--color-primary-500` |
| 图标 | Lucide 或 Heroicons；统一尺寸 16/20/24px | `icon-16`, `icon-20` |

## 7. 交互规范

### 7.1 按钮层级

| 类型 | 样式 | 用途 |
|------|------|------|
| Primary | 主色填充 + 白色文字 | 主要操作：采集、发送、保存 |
| Secondary | 透明背景 + 主色边框 | 次要操作：取消、返回 |
| Danger | 红色填充 | 删除、断开设备 |
| Ghost | 透明 + 悬停高亮 | 工具栏操作 |

### 7.2 表单规范

- 标签左对齐或顶部对齐（移动端必须顶部对齐）。
- 错误提示在字段下方，红色文字。
- 必填项用 `*` 标注。
- 长表单按"基础/高级"分组折叠。

### 7.3 加载与空状态

| 场景 | 处理 |
|------|------|
| 页面加载 | Skeleton 占位，避免白屏 |
| 任务运行中 | 进度条 + 实时状态标签 |
| 空数据 | 插图 + 说明 + 操作按钮 |
| 风控/失败 | DiagnosticAlert 组件，给出下一步行动 |

---

## 8. 可访问性（a11y）

- 所有图标按钮必须带 `aria-label`。
- 表单输入必须关联 `<label>`。
- 颜色对比度 ≥ 4.5:1。
- 焦点状态可见（`focus:ring-2 focus:ring-primary-500`）。
- 移动端触摸目标 ≥ 44×44px。

## 10. 决策记录

| 决策 | 原因 |
|------|------|
| 保留 Vanilla JS + Tailwind | 已有大量前端投入，重写成本高于收益 |
| 不引入 shadcn/ui 或 Ant Design | 避免与现有 glass-panel 风格冲突 |
| 移动端优先"看数"而非"编辑" | 运营核心诉求是随时监控；复杂编辑在桌面完成 |
| 底部 Tab 替代汉堡菜单 | 4 个一级导航更适合 Tab，减少点击深度 |
