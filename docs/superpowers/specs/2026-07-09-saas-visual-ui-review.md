# 雷霆捕获系统 Phase 8 视觉 UI 审查报告

> **文档版本**：v1.0  
> **创建日期**：2026-07-09  > **审查方式**：代码静态审查（未运行截图，因需要登录态与真实数据）  
> **审查范围**：`server/static/index.html` 及关联 JS/CSS

---

## 1. 审查结论

**总体 verdict：需要改进（阶段 5 重点）**

当前管理后台在桌面端视觉风格统一（深色 glass-panel），但存在明显的移动端可用性与可访问性缺口。由于本次 Phase 4–6 主要聚焦后端安全与租户隔离，前端未做改动；阶段 5 必须按 `2026-07-09-saas-uiux-design.md` 实施响应式改造。

## 3. 发现的问题

### 3.1 移动端布局（P0）

| 问题 | 位置 | 影响 | 建议修复 |
|------|------|------|----------|
| 侧边栏固定 240px，移动端未隐藏/转换 | `index.html` 中 `.sidebar` 类 | 375px 下内容被挤出可视区 | 改为底部 Tab 或汉堡菜单 |
| 表格未做卡片化适配 | 线索池/任务中心表格 | 小屏下横向滚动或文字截断 | 改用卡片列表 + 抽屉详情 |
| 统计卡片未换行 | 控制中心 `.grid-cols-4` 等 | 小屏下被严重压缩 | 改为 `grid-cols-1 sm:grid-cols-2 lg:grid-cols-4` |
| 操作按钮组未堆叠 | 项目详情页顶部操作区 | 小屏按钮重叠 | 使用 `flex-col sm:flex-row` |

### 3.2 可访问性（P1）

| 问题 | 位置 | 影响 | 建议修复 |
|------|------|------|----------|
| 部分图标按钮缺少 `aria-label` | 搜索、刷新、设置图标 | 屏幕阅读器无法识别 | 全部添加 `aria-label` |
| 表单输入与 label 未显式关联 | 登录/项目配置表单 | 辅助技术无法聚焦说明 | 使用 `<label for="id">` |
| 错误提示依赖 toast 弹窗 | 全局 toast 容器 | 视力障碍用户可能错过 | 关键错误同时 inline 显示 |
| 颜色对比度待验证 | cyan-400 on slate-900 | 可能低于 WCAG AA | 用 axe-core 扫描确认 |
| 焦点状态不明显 | 自定义 glass 输入框 | 键盘用户难以定位 | 添加 `focus:ring-2 focus:ring-cyan-500` |

### 3.3 一致性与性能（P2）

| 问题 | 位置 | 影响 | 建议修复 |
|------|------|------|----------|
| 引入 Google Fonts | `index.html:12-15` | 国内网络可能加载慢 | 使用系统字体栈 fallback |
| 部分动画可能引发不适 | `.glass-card:hover` 位移 + 阴影 | 对前庭功能障碍者不友好 | 提供 `prefers-reduced-motion` 媒体查询 |
| 无加载骨架屏 | 首次进入页面 | 白屏/闪烁 | 在 `#app-root` 使用骨架占位 |

## 4. 推荐优先级

```
P0（阶段 5 必须）：
├── 侧边栏 → 底部 Tab
├── 表格 → 卡片列表
├── 统计卡片响应式断点
└── 操作按钮堆叠

P1（阶段 5 建议）：
├── 图标按钮 aria-label
├── label 关联
├── 焦点环
└── 错误 inline 提示

P2（阶段 5 后续）：
├── 字体 fallback
├── prefers-reduced-motion
└── 骨架屏
```
